# Project Instructions: EV-HUB-PRO

## Tech Stack
- TypeScript / Next.js 15 / React 19 / Tailwind CSS / Radix UI / Vitest

## Code Style
- Strict TypeScript typing with Zod schemas for input validation.
- Functional React components with hooks.
- Kebab-case filenames for route segments and components.

## Testing
- Run tests: `npx vitest run`
- Test conventions: `tests/**/*.test.ts`

## Conventions
- Git commits: Semantic commits (`feat:`, `fix:`, `docs:`, `test:`).
- Geospatial coordinates must follow `[latitude, longitude]` standards.
